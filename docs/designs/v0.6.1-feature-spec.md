# v0.6.1 功能与修复规格说明书

## 1. 背景与目标
解决用户反馈的 3 个历史遗留问题并实现 2 项核心交互升级：
1. **主面板滚动修复**：上次添加小组件后，HudApp 中泄漏的 `:global(#app) { overflow: hidden !important; }` 导致主面板无法滚动，内容被裁切。
2. **GitHub Release 发布说明修复**：release.yml 缺失 `releaseBody` 配置导致发布页面内容空白。修复该 workflow，并使用 GitHub CLI 补齐已发布的 v0.6.0 页面说明。
3. **速率计算重构**：由最近 2 轮对话汇总 `(out1 + out2) / (dur1 + dur2)` 算出真实 tokens/s，解析层采集真实请求-响应耗时（`duration_ms`），闲置时不重置为“—”，持续保持显示最新有效速率。
4. **HUD 多激活会话展示**：当存在多个激活会话时，HUD 极简胶囊多行垂直平铺展示最近 1~N 条会话（默认 3 条），窗口高度自适应；状态栏（托盘）菜单提供 1/2/3/5 条单选配置；状态栏菜单栏数字始终展示今日聚合汇总数据。
5. **HUD 与小组件独立透明度**：极简胶囊与卡片小组件各自可配置 50%、70%、80%、90%、100% 透明度，背景呈现磨砂通透质感，文字/数字保持 100% 纯白清晰。可在状态栏菜单与右键菜单中随时调节。

## 2. 数据库与数据解析架构 (Schema v6)

### 2.1 SQLite Schema v6
在 `src-tauri/src/core/store.rs` 的 `migrate()` 中新增：
```sql
ALTER TABLE usage_records ADD COLUMN duration_ms INTEGER;
PRAGMA user_version = 6;
```
同时在 `UsageRecord` 结构体新增 `pub duration_ms: Option<i64>`。

### 2.2 耗时采集逻辑
- **OpenCode**：`time.completed - time.created`（毫秒）。
- **Claude Code**：维护会话解析状态，从最近一个 `user` 或 `tool_result` 的 `timestamp` 到本次 `assistant` 的 `timestamp` 之差。
- **Codex**：从对应 `turn_id` 的 `task_started.started_at` 到 `token_usage_record.timestamp` 之差。
- **Cline / Roo**：从 `say: api_req_started` 时间戳到生成记录时间戳之差。
- **omp**：从最近 tool_result 或 prompt 时间戳到完成时间戳之差。
- **兜底**：若解析未获取到单轮起止（历史数据或单点事件），若同会话前一轮记录在 60s 内，可推算差值；否则为 None。

### 2.3 速率计算规则 (Rate Calculation)
在 `src-tauri/src/core/agg.rs` 中：
取当前激活会话（或最近活跃会话）最近的 2 条记录 $R_1, R_2$：
- 输出总和 $out = R_1.output + R_2.output$。
- 耗时总和 $dur = R_1.duration + R_2.duration$（若无 duration 则回退相邻时间戳差值 $\Delta t \le 60s$；若只有单轮则取单轮）。
- 速率 = $out / (dur / 1000.0)$。
- **闲置状态保护**：若当前无新轮次产出，沿用已计算出的最新非零速率；前端在 `summary.current_rate > 0` 时展示 `XX/s`，仅在会话完全无记录时显示 `—`。

## 3. 设置项与状态栏架构 (AppSettings & Tray)

### 3.1 AppSettings 新增字段
在 `src-tauri/src/app_settings.rs`:
```rust
pub struct AppSettings {
    ...
    /// 极简胶囊透明度（0.5 ~ 1.0，默认 0.9）
    #[serde(default = "default_capsule_opacity")]
    pub capsule_opacity: f64,
    /// 卡片小组件透明度（0.5 ~ 1.0，默认 0.95）
    #[serde(default = "default_widget_opacity")]
    pub widget_opacity: f64,
    /// HUD 激活会话最多展示条数（1/2/3/5，默认 3）
    #[serde(default = "default_hud_active_sessions_count")]
    pub hud_active_sessions_count: usize,
}
```

### 3.2 托盘菜单与右键菜单
- 状态栏托盘菜单：
  - 始终显示今日全局汇总（`tray_metric`，与多会话展示完全解耦）。
  - 新增子菜单「活跃会话展示数」：单选 `1 条` / `2 条` / `3 条 (默认)` / `5 条`。
  - 新增子菜单「胶囊透明度」：单选 `100% (不透明)` / `90%` / `80%` / `70%` / `50%`。
  - 新增子菜单「小组件透明度」：单选 `100% (不透明)` / `90%` / `80%` / `70%` / `50%`。
- HUD 原生右键菜单：
  - 增加当前形态对应的透明度快捷调节项。

## 4. 前端渲染与自适应尺寸 (Frontend UI)

### 4.1 滚动 Bug 修复
在 `ui/src/HudApp.svelte` 中，消除 `:global(#app) { overflow: hidden !important; }`，将其严格限制在 `html[data-hud]` 作用域内：
```css
:global(html[data-hud]),
:global(html[data-hud] body),
:global(html[data-hud] #app) {
  ...
}
```
确保主面板 `#app` 的 `overflow-y: auto` 顺畅工作。

### 4.2 HUD 多会话多行平铺
- `HudSummary` 扩展 `active_sessions: Vec<ActiveSessionItem>`，包含每条激活会话的 `session_id`, `model`, `output_tokens`, `session_total`, `current_rate`。
- 极简胶囊垂直平铺展示 1~N 行（N = `hud_active_sessions_count` 与实际激活会话数的交集）。
- 每行高 28px，间距 4px，窗口高度随行数自适应调整：`height = 16 + N * 32`。
- 桌面小组件在走势图下方或指标区联动展示活跃会话切片。

### 4.3 独立透明度
在 `HudApp.svelte` 中挂载 CSS 变量 `--bg-opacity`：
- Capsule 模式：`background: rgba(22, 24, 29, var(--capsule-opacity))`
- Widget 模式：`background: rgba(24, 26, 32, var(--widget-opacity))`
文字、标签、数字不受影响，保持纯白清晰高亮。
