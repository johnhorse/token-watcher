> 前置标准：token-watcher-design-v1.1.md、docs/designs/v0.3-multi-engine-spec.md

## 1. 目标与范围

在 v0.3 中，Token Watcher 实现了 Claude Code（`~/.claude`）与 Codex CLI（`~/.codex`）的双根并行监听与统一四维 Token 归一化。
在 v0.4 中，我们将数据源矩阵扩展至社区主流开源 AI 编程工具：
1. **Cline**：基于 VS Code `globalStorage/saoudrizwan.claude-dev/tasks`，直读本地 `ui_messages.json` 与 `api_conversation_history.json`；
2. **Roo Code**：基于 VS Code `globalStorage/rooveterinaryinc.roo-cline/tasks`，同构解析本地任务记录；
3. **Aider**：基于终端协同工具 `~/.aider.analytics.jsonl`（或 `~/.aider/analytics.jsonl`），增量读取 `message_send` JSONL 流；
4. **Cursor**：**明确非目标（Non-goals）**：经实测，Cursor 本地 SQLite（`state.vscdb`）只存行数与百分比，无 Token 落盘；且经第二意见审查，在代理层伪造 SSE Token 铸造与 OpenAI 上游分流复杂度极高。因此 v0.4 **坚决不引入投机性代理伪造代码**，仅在 UI/文档中给出 Cursor 接入指引。

## 2. 审查加固决议（P0 / P1 全部定案）

| 编号 | 级别 | 审查决议与加固规则 |
|---|---|---|
| **D24** | **P0** | **四维归一化按 `apiProtocol` 严格分支**：<br>1. `apiProtocol == "anthropic"`：Anthropic API 返回的 `tokensIn` 已排除了缓存，**绝对不能再减 cache**！$\text{net\_input} = \text{tokensIn}$，$\text{cache\_read} = \text{cacheReads}$，$\text{cache\_creation} = \text{cacheWrites}$，$\text{output} = \text{tokensOut}$；<br>2. `apiProtocol == "openai"`：OpenAI 包含式口径，$\text{net\_input} = \text{tokensIn} - \text{cacheReads} - \text{cacheWrites}$。若 $\text{tokensIn} < \text{cacheReads} + \text{cacheWrites}$，判定为非法坏行（Bad line）拒绝入库，坚决不静默兜底。 |
| **D25** | **P0** | **剥离 Cursor 代理计费子系统**：v0.4 纯聚焦本地文件直读，不做代理层 SSE 流式 Token 伪造，确保代理架构纯净。 |
| **D26** | **P1** | **主键脱离数组索引，改用稳定内容键**：<br>Cline / Roo 改写 `ui_messages.json` 时支持 Rewind/Retry，数组下标不稳定。主键定为：<br>$\text{record\_id} = \text{format!("{engine}:{task_id}:{ts_ms}:{content_hash_8}")}$<br>利用事件内置时间戳 `ts` 与条目内容哈希前 8 位，确保 Rewind 不双计、不覆写。 |
| **D27** | **P1** | **三类独立数据源扫描器（防 HOME 遍历与通道硬编码）**：<br>废弃纯 `*.jsonl` 目录假设，数据源抽象为：<br>1. `JsonlDir`：递归目录扫描 `*.jsonl`（Claude / Codex）；<br>2. `TaskJsonDir`：扫描 `tasks/*/ui_messages.json`（Cline / Roo）；<br>3. `SingleJsonlFile`：单文件字节续读（Aider）。严禁以 HOME 为根做无界递归。 |
| **D28** | **P1** | **Store 层归因严格物理隔离**：<br>修改 `store.rs` 归因分支，非 Claude/Codex 且非 Proxy 的记录，一律归入独立/Unknown 档案，严禁误串进 Claude Code 订阅卡片。 |
| **D29** | **P1** | **Aider 30 分钟时间切片确定性切分会话**：<br>Aider 单文件内 `user_id` 为常量，按 `(user_id, time 间隙 > 30min)` 动态切分 `session_id`（如 `aider:{user_id_8}:{first_ts}`），使 Flight Recorder 下钻具备真实单次会话颗粒度。 |
| **D30** | **P1** | **Cline 宽容模型提取与防撕裂写三态容错**：<br>扫描 `api_conversation_history.json` 中的 `<environment_details>` 块，容忍换行与属性，提取 `<model>` 标签，缺失则兜底 `"unknown"`；`ui_messages.json` 发生写入半截导致 JSON 非法时，不推进 checkpoint、不计坏行、静默等待下次落盘。 |

## 4. 解析与归一化实现契约

### 4.1 Cline & Roo Code 解析器 (`parse_cline_roo`)
- **扫描**：遍历 `ui_messages.json` 数组，筛选 `entry.type == "say" && entry.say == "api_req_started"`；
- **时间戳**：提取 `entry.ts`，解析为毫秒级 `timestamp_ms`（支持 ISO 8601 字符串与 Unix 毫秒数字）；
- **Payload**：解析 `entry.text` JSON，提取 `tokensIn`, `tokensOut`, `cacheReads`, `cacheWrites`, `cost`, `apiProtocol`；
- **模型**：读取同级 `api_conversation_history.json`，查找最后一个 `<environment_details>` 块内部的 `<model>`；
- **归一化**：严格遵循 D24 决议；
- **唯一键**：严格遵循 D26 决议。

### 4.2 Aider 解析器 (`parse_aider_line`)
- **筛选**：`line.event == "message_send"`；
- **时间戳**：`line.time * 1000`（Unix 秒转毫秒）；
- **字段**：
  - `model = line.properties.main_model`；
  - `input_tokens = line.properties.prompt_tokens`；
  - `output_tokens = line.properties.completion_tokens`；
  - `cache_read = 0`，`cache_creation = 0`；
- **会话划分**：严格遵循 D29 决议。

## 5. 展示层与引擎识别

### 5.1 识别规则 (`agg.rs`)
```rust
pub fn detect_engine(record_id: &str, entrypoint: &str) -> &'static str {
    if record_id.starts_with("codex:") || entrypoint.starts_with("codex") {
        "codex"
    } else if record_id.starts_with("cline:") || entrypoint.starts_with("cline") {
        "cline"
    } else if record_id.starts_with("roo:") || entrypoint.starts_with("roo") {
        "roo"
    } else if record_id.starts_with("aider:") || entrypoint.starts_with("aider") {
        "aider"
    } else {
        "claude"
    }
}
```

### 5.2 UI 工控微徽标规范
在 `SessionList.svelte` 与 `FlightRecorder.svelte` 中，根据 `session.engine` 显示行内微徽标（9px，等宽，满足 WCAG AA 4.5:1 对比度）：
- `[Claude]`：Amber（主信号色）
- `[Codex]`：Teal / Emerald
- `[Cline]`：Ice Blue
- `[Roo]`：Terracotta
- `[Aider]`：Indigo
