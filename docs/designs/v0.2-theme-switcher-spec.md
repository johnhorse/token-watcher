# v0.2 主题切换器（Theme Switcher: Slate/Mint）设计规约

> 状态：定案（经 Codex & agy 双模型第二意见深度审查与工程加固）  
> 日期：2026-10-20  
> 目标版本：v0.2.0  
> 前置标准：token-watcher-design-v1.1.md（路线图第 5 位）、Meter Face 诚实仪表美学

---

## 1. 为什么需要主题切换器

在 Token Watcher v0.1 与 v0.2 前期版本中，全站仅提供单一的「Meter Face」经典暖黑/仪表盘棕色主题。

### 1.1 用户诉求与设计定位
1. **开发者审美多样性**：
   - 经典暖灰工控仪表风（Meter Face）；
   - 现代高冷、低对比疲劳石板灰（Calibrated Slate）；
   - 极客深邃冷绿、高能薄荷脉冲荧光感（Mint Pulse）。
2. **多窗口视觉统一**：
   - 桌面角落 HUD 悬浮窗与主面板在不同工作桌面共存，强调色（Pulse / LIVE 状态）与主界面统一基调，形成品牌凝聚力。
3. **首屏零闪烁（Zero-FOUC）**：
   - 桌面 Native 应用严禁在启动或重载时出现样式闪烁，首帧平滑呈现。

## 2. Codex & agy 双模型审查裁决清单（P1 ~ P2 全部收敛）

经由 Codex 与 agy 联合深度审查，针对草案存在的漏洞与边界问题作出统一裁决与加固：

| 级别 | 问题项 | 风险与表现 | 工程加固裁决与落地方案 |
|---|---|---|---|
| **P1-1** | 亮色模式强调色对比度不达标 | 原亮色 `--accent`（meter `#d97706` 2.78:1, slate `#0284c7` 3.74:1, mint `#059669` 3.60:1）全低于 WCAG AA 4.5:1 | 亮色模式 `--accent` 统一下调至合规档位：meter `#92400e` (4.85:1), slate `#0369a1` (5.42:1), mint `#047857` (5.24:1) |
| **P1-2** | 存量缺失 Token 补齐 | 组件大量引用的 `--text-1`、`--bg-1`、`--bg-2` 在原 CSS 变量中未定义，导致样式退化或透明 | 补齐全套 6 组块中的 `--text-1`（强调主字）、`--bg-1`（面板中层底）、`--bg-2`（微交互按钮底） |
| **P1-3** | HUD 钉死暗底与亮色翻转冲突 | HUD 窗口为固定深色磨砂胶囊底，若系统切亮色，其 `html` 继承浅色深字 tokens 导致字底同黑（2.34:1） | HUD 窗口根元素标记 `data-hud="true"`，CSS 规则限定亮色 media 查询仅对 `:not([data-hud])` 生效，HUD 始终使用暗色基底 + 当前主题暗色 `--accent` |
| **P1-4** | CSS 兜底层与未知主题容错 | 原选择器 `html[data-theme="meter-face"], :root:not([data-theme])` 导致未知 theme 值（如手改或升级残留）全站样式裸奔 | 恢复无条件 `:root { ...meter-face 默认全量 tokens }`，未知或脏值自然优雅回退至经典 Meter Face |
| **P1-5** | 真源挂载期对账与失败回滚 | 仅靠点击事件写 settings.json，挂载期从未对账，写入失败时 localStorage 与磁盘永久分歧 | ① `App.svelte` 与 `HudApp.svelte` 在 `onMount` 异步调用 `get_theme()` 与本地水合对账；② `set_theme` 失败时回滚本地状态并显示 ErrorBanner；③ 磁盘写成功后才广播 `theme-changed` |
| **P2-1** | AppSettings 反序列化容错 | 手改或降级写入未知主题名导致反序列化失败，进而导致整个 `settings.json`（含 HUD 坐标）被重置 | `ThemeMode` 使用 serde 宽松容错或未知值兜底，解析失败时退回默认 `MeterFace`，绝不覆写其它已有配置 |
| **P2-2** | 全量硬编码色 Token 化 | HUD 的 `.hud-total-val color:#f59e0b`、ProxyBar 的 rgba 琥珀底为硬编码 | 全量重构成 `var(--accent)` 与 `color-mix(in srgb, var(--accent) 15%, transparent)` |
| **P2-3** | Mint 次级文本层级倒挂 | Mint 暗色 `--text-2`（`#6ee7b7`）比 `--accent`（`#10b981`）更亮，主次颠倒 | Mint 暗色 `--text-2` 调整为沉稳鼠尾草绿 `#78988b`（对比度 5.1:1），`--accent` 保持高亮薄荷 `#10b981` |

### 3.2 零闪烁（Zero-FOUC）注入机制 (`ui/index.html`)

在 `<head>` 顶端注入防闪烁脚本（含 try-catch 保护，容忍 WebKit 隐私模式）：
```html
<script>
  (function () {
    try {
      var t = localStorage.getItem("token_watcher_theme");
      if (t === "slate" || t === "mint" || t === "meter-face") {
        document.documentElement.setAttribute("data-theme", t);
      }
    } catch (e) {}
  })();
</script>
```

### 3.3 后端持久化与 IPC 契约

#### 3.3.1 Rust 状态结构 (`src-tauri/src/app_settings.rs`)
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum ThemeMode {
    MeterFace,
    Slate,
    Mint,
    #[serde(other)]
    Unknown,
}

impl Default for ThemeMode {
    fn default() -> Self {
        Self::MeterFace
    }
}

impl ThemeMode {
    pub fn as_str(&self) -> &'static str {
        match self {
            Self::MeterFace | Self::Unknown => "meter-face",
            Self::Slate => "slate",
            Self::Mint => "mint",
        }
    }

    pub fn from_str_loose(s: &str) -> Self {
        match s {
            "slate" => Self::Slate,
            "mint" => Self::Mint,
            _ => Self::MeterFace,
        }
    }
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(default)]
pub struct AppSettings {
    pub tray_metric: TrayMetric,
    pub hud_visible: bool,
    pub hud_locked: bool,
    pub hud_x: Option<i32>,
    pub hud_y: Option<i32>,
    pub theme: ThemeMode,
}
```

#### 3.3.2 IPC 指令 (`src-tauri/src/commands.rs`)
- `get_theme(state: State<'_, AppState>) -> Result<String, String>`：读取当前 settings 的 theme 字符串；
- `set_theme(app: AppHandle, state: State<'_, AppState>, theme: String) -> Result<(), String>`：
  - 解析并保存到 `settings.json`；
  - 写入成功后，调用 `app.emit("theme-changed", theme_str)` 广播至所有窗口。

### 3.4 前端组件联动与 HUD 加固

1. **`App.svelte`**：
   - 挂载期 `onMount` 异步调用 `adapter.getTheme()`，若与当前 `data-theme` 不一致，则校准并回写 `localStorage`；
   - 右上角切换按钮：`[ ◓ Meter ]` / `[ ◓ Slate ]` / `[ ◓ Mint ]`，点击触发循环切换；
   - 先调用 `adapter.setTheme(next)`，若失败回滚 `localStorage` 与 `data-theme`。
2. **`HudApp.svelte`**：
   - 根标签标记 `document.documentElement.setAttribute("data-hud", "true")`；
   - `onMount` 同样拉取 `adapter.getTheme()` 或监听 `theme-changed`，设置 `data-theme`；
   - `.hud-pill.pulsing` 的边框和光晕使用 `var(--accent)`；
   - `.hud-total-val` 移除固定 `#f59e0b`，改为 `color: var(--accent)`。
3. **`ProxyBar.svelte`**：
   - 琥珀底色与边框由写死 rgba 调整为 `color-mix(in srgb, var(--accent) 15%, transparent)` 及 `color-mix(in srgb, var(--accent) 30%, transparent)`。

## 4. 验证与验收标准

1. **WCAG 对比度断言**：三套主题在暗色与亮色下的所有文本和强调色经实测计算均 ≥ 4.5:1，结构线和边框 ≥ 3.0:1。
2. **零闪烁（Zero-FOUC）**：浏览器与 Tauri 环境下冷启动与刷新无白屏闪烁或错色闪烁。
3. **跨窗口热切**：主界面点击切换时，主界面与 HUD 悬浮窗的强调色毫秒级同步生效。
4. **异常容错与回退**：
   - `settings.json` 中注入未知主题名 `"theme": "unknown"` 时，Rust 正确解析并回退为 `MeterFace`，不破坏已有其它设置；
   - localStorage 被禁用或清理时，能无缝从后端 `settings.json` 对账恢复。
5. **代码质量**：
   - `cargo test` 全部测试通过；
   - `cargo clippy --all-targets -- -D warnings` 零警告；
   - `npm run build` 前端构建顺利通过。
