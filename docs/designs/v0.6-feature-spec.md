# Token Watcher v0.6 功能升级规约（Autostart、Update Check、Desktop Widget）

## 1. 目标与范围

### 目标
1. **开机自启动**：安装/首次运行默认启用开机启动，用户可在托盘菜单随时选择开启或关闭；
2. **版本更新通知**：检测 GitHub 仓库最新 Release，若有新版本则在主面板顶部以优雅横幅提醒，点击直达 GitHub Release 页面；
3. **桌面小组件**：将现有 HUD 扩展支持「卡片小组件」与「极简胶囊条」两种形态切换。小组件卡片内容范围：主面板顶部总览（大字总数、四维消耗、金额估算）、今日走势脉冲图、模型消耗 Top 3 分布，超出 3 个模型时显示「更多模型」并可点击打开主面板。

### 非目标 (Non-Goals)
- 不做多窗口并存（桌面小组件与极简胶囊共用 HUD 窗口，按设置切换形态，避免多窗口冗余与托盘菜单混乱）；
- 小组件卡片不放时间跨度（RangeChips）与引擎（EngineChips）筛选器，默认且固定展示「今日 + 全部引擎」实时聚合；
- 版本更新不做侵入式系统弹窗或强制阻塞更新，仅在主面板展示非阻塞通知横幅。

## 2. 详细技术方案

### 2.1 开机自启动 (Autostart)
1. **后端依赖**：
   - 使用 `tauri-plugin-autostart = "2"`（在 macOS 上使用 `MacosLauncher::LaunchAgent`，在 Windows 上使用注册表）。
2. **配置持久化与状态同步** (`src-tauri/src/app_settings.rs`)：
   - `AppSettings` 新增字段：
     ```rust
     pub autostart: Option<bool>, // None 表示首次启动，默认行为视为 true
     ```
   - 首次启动检测：若 `autostart.is_none()`，调用 `autolaunch().enable()`，并将 `autostart` 显式持久化为 `Some(true)`。
3. **托盘菜单控制** (`src-tauri/src/tray.rs`)：
   - 托盘菜单新增 `CheckMenuItem`，ID 为 `autostart`；
   - 文案：中文 `开机自动启动`，英文 `Launch at Startup`；
   - 勾选状态与 `settings.is_autostart_enabled()` 保持一致；
   - 用户点击后：
     - 若当前已启用：调用 `autolaunch().disable()`，更新 `settings.autostart = Some(false)`，保存并更新勾选状态；
     - 若当前未启用：调用 `autolaunch().enable()`，更新 `settings.autostart = Some(true)`，保存并更新勾选状态。

### 2.2 版本更新通知 (Update Check)
1. **更新检测模块** (`src-tauri/src/update.rs`)：
   - GitHub Releases API：`https://api.github.com/repos/johnhorse/token-watcher/releases/latest`；
   - 请求头带上 `User-Agent: token-watcher/{version}`，超时 5 秒；
   - 版本解析：去掉 `v` 或 `V` 前缀，按语义化版本 `major.minor.patch` 解析比对；
   - 返回结构体：
     ```rust
     #[derive(Debug, Clone, Serialize, Deserialize)]
     pub struct UpdateInfo {
         pub has_update: bool,
         pub current_version: String,
         pub latest_version: String,
         pub release_url: String,
     }
     ```
2. **IPC 命令** (`src-tauri/src/commands.rs`)：
   - `check_update(app: AppHandle) -> Result<UpdateInfo, String>`：
     - 优先返回内存缓存；若超过 6 小时或首次查询，异步拉取并更新缓存；
   - `open_external_url(url: String) -> Result<(), String>`：
     - 校验 `http://` 或 `https://` 协议后，使用操作系统原生命令（`open` / `cmd start` / `xdg-open`）打开浏览器。
3. **前端呈现** (`ui/src/App.svelte`)：
   - 页面挂载时调用 `adapter.checkUpdate()`；
   - 若 `updateInfo.has_update` 且本会话未被用户关闭：
     在主面板顶部展示置顶横幅（Banner）：
     `🎉 发现新版本 vX.Y.Z · [查看更新] [✕]`；
   - 点击「查看更新」调用 `adapter.openExternalUrl(url)`；
   - 点击 `✕` 记录到前端状态，本次运行不再展示。

### 2.3 桌面卡片小组件 (Desktop Card Widget)
1. **形态枚举与配置** (`src-tauri/src/app_settings.rs`)：
   ```rust
   #[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
   #[serde(rename_all = "kebab-case")]
   pub enum HudMode {
       #[default]
       Widget,  // 卡片小组件（默认 320x390px）
       Capsule, // 极简胶囊条（250x34px）
   }

   pub struct AppSettings {
       // ...
       pub hud_mode: HudMode,
   }
   ```
2. **窗口尺寸与布局管理** (`src-tauri/src/hud.rs`)：
   - 胶囊模式标准尺寸：`250px × 34px`；
   - 小组件模式标准尺寸：`320px × 390px`；
   - `resize_hud(width: f64, height: Option<f64>)`：支持同时调整宽高；
   - 切换形态命令：`set_hud_mode(mode: String)`：
     - 保存至 `settings.json`；
     - 调整 HUD 窗口尺寸并触发安全边界校准；
     - 广播 `hud-mode-changed` 事件；
     - 同步托盘菜单与 HUD 右键菜单状态。
3. **右键菜单与托盘菜单**：
   - 托盘菜单：
     - 显示桌面 HUD/小组件
     - 形态: 卡片小组件 / 形态: 极简胶囊（切换）
     - 锁定 HUD (鼠标穿透)
   - HUD 悬浮窗右键菜单：
     - 提供形态切换菜单项（如当前是卡片，显示「切换为极简胶囊」；反之显示「切换为卡片小组件」）；
     - 保留锁定与指标选项。
4. **前端实现** (`ui/src/HudApp.svelte` 及组件)：
   - `data-mode="widget"` 与 `data-mode="capsule"` 属性；
   - 当 `hud_mode === "widget"` 时：
     - **Header**：左侧为今日标签与预估费用（`$0.xx`），右侧为主题切换图标、形态切换图标（切换回胶囊）与拖拽手柄；
     - **Totals**：大字显示总 Token 数（支持点击切换精确/紧凑格式），下方展示 Input / Output / Cache Read / Cache Write 四项指标；
     - **Chart**：今日脉冲走势图；
     - **ModelsBar**：
       - 截取消耗量最多的前 3 个模型；
       - 若模型数量 > 3，在底部展示一行精致的按钮/入口：`+N 更多模型 →`（或 `更多模型`）；
       - 点击「更多模型」调用 `adapter.showMainWindow()` 呼出并聚焦主窗口。
   - 当 `hud_mode === "capsule"` 时：保持现有的 34px 极简速率/缓存率胶囊条。
